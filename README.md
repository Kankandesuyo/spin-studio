# Fate Wheel · 自定义转盘

一个无依赖、无需登录的静态网页。默认 10 份，5 份「换」、5 份「不换」。

## 使用

设置 2–30 份，编辑每份文字和大小权重，点击「开始转动」。权重 1 和 3 对应 25% 和 75%。修改后自动保存到当前浏览器。过窄的扇区显示序号，较长内容省略展示，编辑区和最终结果保留完整文字。

文字层与转盘图形分开渲染，文字随扇区移动但始终朝上。采用惯性减速、随机停点和指针弹动，可选咔嗒音效。系统开启减少动态效果时直接显示结果。

## 本地运行

安装 Python 后，在此目录运行 `python -m http.server 5180 --bind 127.0.0.1`，打开 http://127.0.0.1:5180 。使用 ES Modules，需通过 HTTP 访问。

安装 Node.js 后运行 `npm test` 验证权重、角度定位、输入边界和减速曲线。网页本身没有 npm 依赖，无需构建。

## 结构

- `index.html`：页面布局与转盘结构。
- `ui.css`：桌面与手机样式。
- `glass.css`：按 Liquid Glass 原则实现的网页材质层，包含背景模糊、边缘高光、交互反射、深色模式与无模糊降级；不是 iOS 原生 API。
- `core.js`：权重、扇区几何和抽取定位。
- `app.js`：编辑、动画、音效与本地保存。
- `tests/core.test.js`：计算逻辑验证。

## 随机方式与安全

使用浏览器 `crypto.getRandomValues` 生成连续均匀停点，每份概率等于其面积占比。转动时锁定配置，避免结果与图形不一致。界面使用 `textContent` 写入用户文字，不解析用户 HTML。权重限制为 0.01–10000，文字最多 40 个字符。

没有后端、第三方脚本、数据上传、账号或密钥。配置只写入当前浏览器 localStorage，不随 GitHub 仓库发布。Content Security Policy 禁止网页网络请求和内联脚本。该工具适用于日常选择，客户端代码可被使用者修改，不提供可审计抽奖承诺。

## GitHub Pages

将静态文件推送到仓库 `main` 分支，在 Settings → Pages 中选择 Deploy from a branch、`main`、`/(root)`，保存即可。`.nojekyll` 禁用 Jekyll 处理。
